# Summarize Case-Dropping Stability Results

Summarize Case-Dropping Stability Results

## Usage

``` r
# S3 method for class 'tna_stability'
summary(object, ...)

# S3 method for class 'group_tna_stability'
summary(object, ...)
```

## Arguments

- object:

  A `tna_stability` or a `group_tna_stability` object.

- ...:

  Ignored.

## Value

A `data.frame` with one row per centrality measure (and `Edges`, when
the edge weights were assessed), and per group in the first column
`group` for a `group_tna_stability` object, with the columns `measure`
and `cs_coefficient`.

## Examples

``` r
# \donttest{
model <- tna(group_regulation)
# Small number of iterations and drop proportions for CRAN
stability <- estimate_cs(
  model,
  drop_prop = seq(0.3, 0.9, by = 0.2),
  measures = "InStrength",
  iter = 10,
  edges = TRUE
)
summary(stability)
#>      measure cs_coefficient
#> 1 InStrength            0.9
#> 2      Edges            0.9
# }
```
