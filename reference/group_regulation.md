# Example Wide Data on Group Regulation

Students' regulation during collaborative learning. Students'
interactions were coded as: "adapt", "cohesion", "consensus",
"coregulate", "discuss", "emotion", "monitor", "plan", "synthesis"

## Usage

``` r
group_regulation
```

## Format

A `data.frame` with 2000 sequences (rows) and 26 time points (columns
`T1` to `T26`). Shorter sequences end in missing values. The first 1000
rows are the sequences of high achievers and the last 1000 rows those of
low achievers (see `group_regulation_long`).

## Source

The data was generated synthetically.
