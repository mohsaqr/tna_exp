# Plot a Bootstrapped Grouped Transition Network Analysis Model

Plot a Bootstrapped Grouped Transition Network Analysis Model

## Usage

``` r
# S3 method for class 'group_tna_bootstrap'
plot(x, title, ...)
```

## Arguments

- x:

  A `group_tna_bootstrap` object.

- title:

  A `character` vector of titles to use for each plot.

- ...:

  Additional arguments passed to
  [`plot.tna()`](https://sonsoles.me/tna/reference/plot.tna.md).

## Value

A `list` with the plot of each group (see
[`plot.tna_bootstrap()`](https://sonsoles.me/tna/reference/plot.tna_bootstrap.md)),
invisibly.
