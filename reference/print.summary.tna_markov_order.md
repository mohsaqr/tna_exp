# Print a Summary of a Markov Order Test

Print a Summary of a Markov Order Test

## Usage

``` r
# S3 method for class 'summary.tna_markov_order'
print(x, digits = attr(x, "digits"), ...)
```

## Arguments

- x:

  A `summary.tna_markov_order` object.

- digits:

  An `integer`, the number of decimals of the numeric columns other than
  the p-values, which are shown with three decimals.

- ...:

  Ignored.

## Value

`x` (invisibly).
